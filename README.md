A tiny stdlib-only Python program that writes the entry for the "One Word for the Boss" bounty: one bare word, no caption, no trailing newline. The word it writes is Overpromiser, and the program refuses to emit anything longer than one token or 30 bytes.

## The word

> Overpromiser

It names the boss habit everyone has met: he promises the client, the board and
the launch date everything at once, then hands the impossible half of it to you
and walks into the next meeting.

## Run it

```sh
OUTPUT=/tmp/entry.txt python3 main.py
```
